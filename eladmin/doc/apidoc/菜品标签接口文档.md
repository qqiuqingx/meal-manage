# 菜品标签接口文档

## 概述

菜品标签是在菜品维护弹窗内复用的全局字典。一个菜品可绑定多个标签，一个标签可被多个菜品共用。菜品标签与配料标签使用独立数据表和权限，名称可以相同，修改和删除互不影响。标签不参与排餐、客户忌口或配料分类逻辑。

菜品编辑时通过 `tagIds` 整体提交关系：缺省或 `null` 保持原关系，空数组清空，非空数组整体替换。标签名称由服务端读取字典，不接受客户端 `tags` 名称作为写入来源。

## 数据模型

### 菜品标签字典 `dish_tag`

| 字段 | 类型 | 说明 |
|---|---|---|
| id | Integer | 自增标签ID |
| name | String(64) | 标签名称，去除首尾空白后按 `utf8mb4_unicode_ci` 唯一 |
| createTime | Timestamp | 创建时间 |
| updateTime | Timestamp | 最近更新时间 |

### 菜品标签关系 `dish_tag_relation`

| 字段 | 类型 | 说明 |
|---|---|---|
| dishId | Integer | 菜品ID |
| tagId | Integer | 标签ID |

联合主键为 `(dish_id, tag_id)`，并有反向索引 `(tag_id, dish_id)`。删除菜品会清理其关系并保留标签字典。

## 接口列表

### 分页查询标签

```http
GET /api/dish-tags?name=低盐&page=0&size=20
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| name | String | 否 | 标签名称模糊查询 |
| page | Integer | 否 | 零起始页码，默认 0 |
| size | Integer | 否 | 每页数量，默认 20 |

响应为 `{content, totalElements}`，每个标签包含 `id`、`name`、`createTime`、`updateTime`。无标签时 `content` 为空数组。

权限：`dish:list`、`dish:add` 或 `dish:edit` 任一权限可查询，以供菜品列表及表单选择标签。

### 新增标签

```http
POST /api/dish-tags
Content-Type: application/json
```

```json
{"name": "低盐"}
```

成功返回 `201 Created` 和生成的标签对象，例如 `{"id": 12, "name": "低盐"}`。权限：`dishTag:add`。

服务端会去除首尾空白；名称不能为空，最多64个 Unicode 字符，重复名称（包含大小写差异）返回 `400`。

### 修改标签名称

```http
PUT /api/dish-tags
Content-Type: application/json
```

```json
{"id": 12, "name": "少盐"}
```

成功返回 `204 No Content`。权限：`dishTag:edit`。改名保留全部菜品关系，所有菜品之后都会显示新名称；前端确认提示会说明此影响。

### 删除标签

```http
DELETE /api/dish-tags/12
```

成功返回 `200 OK`。权限：`dishTag:del`。只允许删除未被任何已保存菜品引用的标签；仍有引用时返回 `400`，提示先从菜品中移除关联并保存，再删除字典。

菜品弹窗内的字典新增、改名、删除立即生效。菜品与标签的绑定只在菜品保存时提交；取消菜品编辑不会撤销已经完成的字典操作。

## 菜品读写字段

`GET /api/dishes` 和 `GET /api/dishes/{id}` 的每个菜品包含：

```json
{
  "tagIds": [12],
  "tags": [{"id": 12, "name": "少盐"}]
}
```

无标签时两个字段均为空数组。`POST /api/dishes` 和 `PUT /api/dishes` 可提交 `tagIds`。重复ID会去重；null元素、非正数或不存在的标签ID返回 `400`，菜品及标签关系在同一事务中回滚。

## 权限菜单

`dishTag:add/edit/del` 三个按钮权限挂在现有菜品管理菜单下；部署 SQL 不创建独立标签页面，也不默认给角色授权。字典维护角色需由管理员按现有角色授权流程单独分配权限。仅具备菜品新增/编辑权限的用户可查询和绑定已有标签。

部署与回滚步骤见[菜品标签发布清单](../../../docs/plans/dish-tags/release-checklist.md)。表结构脚本为 `eladmin/sql/20260928_dish_tag.sql`。

## 客户禁忌同步副作用

字典新增、改名或删除成功提交后会触发后台重匹配客户保存的禁忌原文，并自动追加未被人工排除的匹配对象；回滚不触发。客户端无新增确认步骤，任务完成后刷新客户/订单页面查看结果。仅改变标签绑定关系或分类排序不触发。客户过敏标签、原文和已有引用名称快照不随该任务改写，现有权限及请求响应结构不变。
