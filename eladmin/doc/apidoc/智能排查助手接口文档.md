# 智能排查助手统一聊天接口文档

## 1. 接口定位

客服聊天统一由主系统会话服务进入 Agent 的 LLM Tool Calling 链路。普通业务查询和排餐问题使用同一个聊天入口；Agent 只调用当前客服有权限使用的只读工具，实时业务事实必须来自本轮成功工具结果。

排餐、客户、订单、核销、退餐、套餐、菜品和运营指标工具的内部接口与权限见《智能客服Agent内部业务查询接口文档》；本接口不再提供单独的直连诊断方法。

## 2. 聊天接口

- Path：`/api/agent/meal-plan/chat`
- Method：`POST`
- Permission：`agentDiagnosis:list`
- Header：可选 `X-Request-Id`

### Request

```json
{
  "sessionId": "session-001",
  "clientMessageId": "message-001",
  "message": "B2200 今天午餐排了什么？"
}
```

字段说明：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `sessionId` | string | 否 | 不填写时由主系统创建会话 |
| `clientMessageId` | string | 否 | 客户端消息幂等键 |
| `message` | string | 是 | 客服自然语言问题 |

会话上下文、工具白名单、数据范围和内部访问令牌由主系统服务端生成，前端不得提交或覆盖。

### Response

```json
{
  "requestId": "request-001",
  "contractVersion": "v2",
  "sessionId": "session-001",
  "clientMessageId": "message-001",
  "status": "ANSWERED",
  "assistantMessage": "已查询到……",
  "facts": [],
  "cards": [
    {
      "type": "MEAL_PLAN_LIST",
      "sourceToolCallId": "call-1",
      "data": {}
    }
  ],
  "toolFacts": [],
  "toolTraceSummary": [],
  "warnings": [],
  "cached": false,
  "partial": false,
  "queriedAt": "2026-08-04T12:00:00+08:00",
  "conversationPatch": {}
}
```

主要字段：

| 字段 | 说明 |
| --- | --- |
| `status` | `ANSWERED`、`NEED_MORE_INFO` 或 `ERROR` |
| `assistantMessage` | Agent 经过最终回答护栏校验的文本 |
| `facts` | 可追溯的工具事实摘要 |
| `cards` | 根据成功工具输出确定性生成的业务卡片 |
| `toolFacts` | 工具名称、调用标识和安全结果摘要 |
| `toolTraceSummary` | 调用状态、结果数量等脱敏追踪信息 |
| `warnings` | 权限不足、空结果、截断或工具失败等稳定告警 |
| `partial` | 是否只返回部分结果 |
| `conversationPatch` | 主系统版本校验后持久化的会话摘要 |

第一期卡片类型包括：

- `CUSTOMER_PROFILE_LIST`
- `SERVICE_CUSTOMER_LIST`
- `SERVICE_CUSTOMER_DETAIL`
- `MEAL_PLAN_LIST`
- `VERIFICATION_LIST`
- `REFUND_LIST`
- `DISH_LIST`
- `DISH_CANDIDATE_LIST`
- `PACKAGE_DETAIL`
- `METRIC_RESULT`
- `BUSINESS_RULE`

金额、价格、完整手机号、完整地址、Token、权限集合、数据范围规则和内部关联 ID 不在客服默认卡片中展示。Agent 不执行写操作，也不得在回答中声称已下单、已排餐、已退款或已核销。

## 3. 会话管理

会话列表、创建、详情、归档和标题更新接口继续使用 `/api/agent/chat-sessions/**`，由当前登录客服的数据权限隔离。消息幂等、会话版本冲突和最近工具摘要由主系统会话服务处理。

## 4. 失败与部分结果

- `NEED_MORE_INFO`：模型无法在当前权限和事实范围内确定查询对象或条件，`warnings` 提供稳定补充原因。
- `ERROR`：模型、工具、权限或安全护栏失败；响应不透传 SQL、内部 URL、堆栈或下游原始异常。
- `partial=true`：至少一个工具失败、结果被截断或详情字段不完整；模型不得将部分结果表述为全部数据。
