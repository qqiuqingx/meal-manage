# Phase 02 暂停订单的完整业务生命周期

## 执行前规则检查

- 重新读取当前生效的 AGENTS.md 规则链、overview、Phase 01 交付记录及客户、订单、排餐、核销、套餐编号池业务文档。
- 全量审计订单 status=1、status!=1 的后端 SQL/Java 与前端枚举使用点；核对现有状态 0/1/2/3 和外部接口调用方。

## 目标

引入 PAUSED(4) 订单状态，使订单余额、客户视图和编号占用保留，但排餐及核销严格停止。

## 前置依赖

- Phase 01 已完成；需要预览草稿中的暂停判定及来源行契约。

## 输入与输出

- 输入：现有订单状态字段与 E/F 含“等通知”的判定。
- 输出：状态枚举与状态转换、查询/权限/页面语义、暂停和恢复接口或现有编辑接口的受控状态操作。

## 本阶段实施约束

- 暂停是有效未完单，必须仍参与编号池占用、客户余额/用餐统计、删除保护和订单冲突；只有 ACTIVE(1) 可排餐与核销。
- H“等通知送餐”餐次为空是另一个维度：不能被现有规范化逻辑改为 ALL，也不能显示为“早午晚”。
- 状态与公共 API/SQL 变更前记录所有调用方影响；退款、完成、恢复按明确状态转移校验，不允许随意从取消/已退餐恢复。

## 涉及文件

- 新增：CustomerOrderStatus 枚举、订单状态注释/菜单权限迁移 SQL、状态流转测试。
- 修改：CustomerOrderServiceImpl、CustomerProfileServiceImpl、CustomerOrderMapper.xml、NumberPoolMapper.xml、MealPlanServiceImpl、MealVerificationServiceImpl、MealRefundServiceImpl、CustomerOrder.java、订单列表和详情/表单相关 Vue 文件、客户和订单接口文档及业务文档。

## 实施步骤

1. 以 enum 统一 0取消、1进行中、2完成、3退餐、4暂停的编码/文案及合法状态转移；普通人工新增和导入两条创建路径均可按规则创建暂停单。
2. 拆分“有效未完单”与“可排餐/可核销”两个查询语义：余额、客户用餐统计、编号池、删除保护、冲突校验包含 1/4；排餐生成、人工新增、核销只认 1。暂停态允许按剩余餐数退餐。
3. 保存、详情、编辑和列表保留 null 餐次类型的“未指定”语义；暂停单恢复时不自动猜午晚餐，按日期计划和餐次校验。
4. 前端订单筛选、表单、客户详情和排餐计划状态提示展示“暂停/待通知”；恢复动作必须有权限并刷新余额/日历。
5. 测试暂停客户在用餐统计仍可见、编号不释放、不能排餐/手动新增/核销、可恢复和退餐、null 餐次不变成 ALL；同步文档。

## 验证方式

- 显式运行订单、编号池、客户用餐统计、排餐和核销相关 Maven 测试；必要的数据库测试只按新增主键清理。
- 用只读 SQL 检查状态过滤范围，验证不会把 4 当作已完成或释放编号。
- 前端 lint/构建及 git diff --check。

## 完成标准

- 暂停单在业务页面可见且保有余额和编号，任何自动/人工排餐与核销均无法执行；恢复后按计划工作。
- 既有状态 0/1/2/3 行为无回归，接口和业务文档一致。

## 阶段交付记录

### 阶段交付记录（2026-09-25）

- 新增 `CustomerOrderStatus` 枚举；订单创建仅允许 ACTIVE(1)/PAUSED(4)，编辑只允许状态不变或 1↔4，已取消/完成/退餐不可恢复。暂停生效日期在暂停或导入时由服务端记录；恢复清空。
- `customer_order` 有效未完订单查询、套餐编号占用、客户统计/删档保护及订单冲突校验包含状态 1/4。排餐候选、原子核销扣减和自动完单仍只接受状态 1。
- 人工新增排餐候选也要求订单状态为 1 且餐次明确；状态 4 与 `mealType=null` 的来源计划不会绕过状态/餐次过滤。
- 暂停订单可退餐；退餐状态更新限定在 1/4，更新失败会回滚退餐流程。订单删除拒绝状态 1/4。
- 合法零单价可逐份核销，每份仍递增核销数、扣减剩余餐数；空单价和负单价拒绝。
- 编辑、订单列表、客户详情和数量日历保留 `mealType=null` 的「待通知」语义；暂停或未指定餐次的来源计划只读，人工排餐需要明确餐次。
- 更新文件包括：`CustomerOrderStatus.java`、`CustomerOrderServiceImpl.java`、`CustomerOrderMapper.xml`、`NumberPoolMapper.xml`、`NumberPoolServiceImpl.java`、`MealPlanServiceImpl.java`、`MealVerificationServiceImpl.java`、`MealRefundServiceImpl.java`、`CustomerProfileServiceImpl.java`、`CustomerMealStatsScheduleUtil.java`、订单与数量网格前端、客户订单/客户/核销接口和业务文档。
