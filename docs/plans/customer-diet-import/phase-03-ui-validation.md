## 实施步骤
1. 导入预览增加想吃/禁忌匹配展示，列明Sheet行列与原词项。唯一匹配展示类型和名称；多匹配提供多选和独立跳过动作；零匹配显示提示。
2. 统计待处理歧义项，未处理完禁用确认。不可导入客户不要求处理其歧义。筛选后隐藏的行仍参与待处理计数。
3. 上传新文件、改日期或重新预览时清空旧选择；服务端要求重新预览时避免沿用过期候选。
4. 确认回传文件摘要、字典摘要和选择；确认文案分别说明新建与补录，提交后显示补录数量、未导入项提示，刷新客户列表。
5. 客户详情分别展示D/E原文块和两字段的对象标签，未匹配/跳过的原文也可核对；客户编辑提供五类对象多选，清空/保留语义与后端一致；新增引用不得自由输入原文；原文只读，编辑对象不覆盖来源文字。
6. 同步客户业务文档、API文档及增量SQL部署顺序，不改无关业务。
7. 执行后端相关回归、前端lint与真实组件/方法交互测试、git diff --check；记录未执行的数据库验证。必要时只读抽查用户原表，禁止把客户原文纳入测试夹具。

## 验证方式与完成标准
- 多选/跳过能提交；未选择阻止提交；未匹配提示可见且不阻断其他匹配项。
- 仅有补录客户时仍可确认；结果显示UPDATED，重传不重复。
- 重预览清空选择；隐藏行歧义仍阻止提交；错误客户不阻塞可导入客户。
- 客户详情原文和匹配对象分别回显，结构化空数组清空不清原文，与旧特殊要求字段分别维护。
- 修改文件lint与相关单元测试通过；相关后端回归通过；文档链接有效、差异无空白错误。
